# Privacy

ChromaMatter processes OBJ, GLB, reference images, projects, and 3MF output
locally. The application does not intentionally upload those files to a server
operated by the ChromaMatter project.

Project, preference, and generated validation files can contain local paths.
The optional owned-filament inventory can contain product information entered
or selected by the user. Review and remove personal paths or inventory details
before sharing any such file.

When reporting a problem, do not attach a private production model, source
image, project, generated 3MF, screenshot containing an identifying filename,
or settings archive. Prefer the error text, application and operating-system
versions, reproduction steps, and a newly created minimal fixture that is safe
to publish.

This portable package contains no user-specific model, generated print project,
account credential, saved user preference, or bundled `DemoData`. It contains
no generated or sample 3MF and no validation sidecars. Optional DemoData is a
separate download from the [official download page](https://chromamatter.app/download),
not part of the application archive. Its own README, NOTICE and manifest describe
the rights-cleared source GLB and reference image. Those rights and payload checks
remain required for the separate demo; they do not authorize other models.
