# Privacy

ChromaMatter processes OBJ, GLB, reference images, projects, and 3MF output locally. The application does not intentionally upload those files to a server operated by the ChromaMatter project.

Project, preference, and generated validation files can contain paths selected or produced on the local PC. The optional owned-filament inventory can contain product information entered or selected by the user. Review and remove personal paths or inventory details before sharing any such file. Generated validation JSON files are excluded from the public `DemoData/3MF/` payload because local paths are not public payloads.

When reporting a problem, do not attach a private production model, source image, project, generated 3MF, screenshot containing an identifying filename, or settings archive. Prefer the error text, application and Windows versions, reproduction steps, and a newly created minimal fixture that is safe to publish.

This portable application package contains no user-specific model, generated user print project, account credential, or saved user preference. The rights-cleared evaluation model and its ChromaMatter-derived 3MF files under `DemoData` are intentional bundled demo payloads.
