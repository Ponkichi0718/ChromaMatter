# ChromaMatter 0.9 Windows版

[English](README_EN.md)

ChromaMatterは、頂点カラー付きOBJまたは対応GLBの色を4本のフィラメントへ割り当て、
Snapmaker Orcaで確認できる3MFプロジェクトを作るデスクトップアプリです。TripoAI、Hi3D AI、
Snapmaker、OpenAI、その他の第三者による公式・提携製品ではありません。

## 0.9の主な変更

主な改良は、**一般的な単一モデルGLBの修復成功率と3MF出力精度の向上**です。
対応関係を確認できた同一座標の継ぎ目を接合し、厳しい条件を満たす微小な不要形状を整理し、
修復可能な小さな平面開口を塞ぎます。形状チェックの初期値［高］では、従来の
閉立体・3MF検証に合格した場合だけ出力します。

複雑な分割モデルへの対応は引き続き入力依存で、修復・出力に失敗する場合があります。
修復を安全停止しても、読み込んだ元の形状・色・手修正は保持されます。失敗時の警告から
3D境界確認画面を開く案内はなくなりました。ラジアル実験もアプリ画面から取り除いています。

## はじめ方

1. ZIP全体を**新しいフォルダ**へ展開します。ZIP内から直接実行せず、旧版のフォルダへ
   上書きしないでください。`ChromaMatter.exe`と`_internal`は同じ場所に置きます。
2. `START_CHROMAMATTER.cmd`または`ChromaMatter.exe`を起動します。
3. ［OBJ／GLBを開く］からモデルを読み込みます。新規設定の初期モードは**Flat Four**です。
   混色を使う場合は**Full Spectrum**を選びます。F1～F4とプレビューを確認し、
   フィラメント色を変更した場合は未適用の変更を反映してください。
4. 画面下部の［出力設定］から別ウィンドウを開き、サイズを確認します。［閉立体化］は
   ［3MFを書き出す］の隣にある独立ボタンです。修復が必要な場合に実行して完了を待ちます。
   大きな欠損や複雑な形状には別の修復ソフトが必要な場合があります。
5. ［3MFを書き出す］で新しい保存先へ出力します。元モデルは残し、後から編集を続ける場合は
   プロジェクトフォルダも保存してください。
6. 3MFをSnapmaker Orcaで**プロジェクトとして開き**、フィラメントの順番、材料、形状、
   スライス結果を確認してから印刷します。

［形状チェック］の初期値は［高］です。［中］［低］［形状の不具合を無視（非推奨）］は
出力時の検証だけを変更し、モデルを修復したり手動の［閉立体化］を緩めたりしません。
［高］以外では問題のある形状も出力される場合があり、毎回確認が必要です。
色とアーカイブ構造の検証はどの設定でも維持します。

このアプリに`DemoData`は**同梱しません**。必要な場合は
[公式ダウンロードページ](https://chromamatter.app/download)から別途ダウンロードしてください。
元GLBと参照画像を使う前に、デモ側のREADME／NOTICE文書と管理用マニフェストを
確認してください。このアプリのパッケージにはサンプルまたは生成済み3MFも**一切同梱しません**。

## Flat Four

- Flat Fourは、広い色領域をF1～F4へ直接割り当てるモードで、新規設定と新しく開く
  モデルの初期値です。
- 意味のある白・黒の細部を保守的に維持します。滑らかな有彩色面にある小さく確度の高い
  白／灰色の照明斑は、周囲の有彩色へまとめる場合があります。
- F1～F4の4枠と3MFの色状態の形式は維持します。手修正が優先されます。
- Full Spectrumも引き続き利用できます。混色が必要な場合に選択してください。

マニュアル修正ではブラシ、エアブラシ、スポイト、塗りつぶし、なじませが使えます。
印刷する色に段階的な陰影を付ける試験的な**セル彩色**・**陰影モノクロ**も利用できます。
結果は元の色・形状・パレット・実際のフィラメントに依存し、手描き塗装の再現を保証しません。

**重要な制限:** 意味を理解するAI認識ではありません。焼き込み照明、影、小さな細部、
曖昧な素材を誤分類する場合があります。分割モデルの閉立体化とパーツ別3MF出力は
入力依存のβ機能です。修復は厳格なまま、出力は選んだ形状チェックの設定で検証します。
出力できても印刷可能性を保証するものではありません。

## 対応範囲と注意

- このパッケージはWindows x64向けです。
- OBJは`v x y z r g b`形式の頂点カラーを想定します。
- GLBは静的な埋め込みベースカラーと`COLOR_0`を対象とします。アニメーション、スキニング、モーフ、
  Draco、meshopt、BasisU、外部URIには対応しません。
- Hi3D系分割GLB対応はβ・非公式です。パーツ識別用`COLOR_0`は、利用できる証拠が
  一致した場合だけ除外し、それ以外の作者指定色は保持します。
- 画面色と実際の造形色は一致を保証しません。同じ材料と造形条件の比較チャートや
  テスト印刷で確認してください。
- モデルを表示・読込できても、自動修復、閉立体化、スライス、印刷可能性を保証しません。

このパッケージは未署名のため、Windowsが保護警告を表示する場合があります。
入手元、対象ZIPのSHA-256、提供されている場合は署名情報を先に確認してください。
Windowsの保護機能を無効にしたり、入手元を確認できないファイルの警告を無条件に回避したり
しないでください。

## プライバシーと不具合報告

モデル処理はPC内で行い、プロジェクト運営者のサーバーへ意図的にアップロードしません。詳しくは
[PRIVACY.md](PRIVACY.md)を参照してください。

公開の不具合報告へ非公開モデルを添付しないでください。ChromaMatterとWindowsのバージョン、
再現手順、エラー文を共有してください。モデルが必要な場合は、公開可能な最小の再現用データを
新しく作成してください。
