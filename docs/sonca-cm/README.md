## Offline / オフラインで読む

1. Choose a language ZIP above and extract the whole folder. / 上から言語別ZIPを選び、全体を展開します。
2. Open `index.html`. / `index.html` を開きます。
3. Keep the images and page folders together. / 画像・ページのフォルダーは一緒に残します。

Each ZIP contains one language and its images, not the application or printable models. Links to the other language open the online guide.

各ZIPに入るのは1言語のマニュアルと画像です。アプリや印刷用モデルは含みません。他言語のリンクはオンライン版を開きます。

## Version and scope / 対象と検証範囲

This manual covers [Sorca CM v1.1](https://github.com/Ponkichi0718/ChromaMatter/releases/tag/sorca-cm-v1.1). Older UI examples, beta features and unverified results are labelled. This update does not establish new print, connector-fit or optical validation.

このマニュアルは **Sorca CM v1.1** が対象です。旧UIの作例・ベータ機能・未確認結果は本文で区別しています。今回の更新は新たな実印刷・ダボ嵌合・光学検証を示すものではありません。
