# 非公開サンプル・公開デモ素材の運用方針

更新日: 2026-08-06  
対象: ChromaMatter の開発、検証、公開資料、紹介動画

## 目的

実際のモデルで十分に検証しながら、公開リポジトリや配布物へ個人データ、権利不明の画像、モデル、3MF を混入させないための方針です。

「自分用の検証ファイル」と「公開専用に新規作成したデモモデル」を分けて管理します。手元にある既存の実モデルを後から公開デモへ移す運用は行いません。

## 1. 公開範囲の三分類

### A. 公開リポジトリ・配布物に含めてよいもの

- プログラムで新規生成した単純形状の OBJ
- 自作の頂点カラー付き合成メッシュ
- ブランド、既存キャラクター、人物を含まないテスト用データ
- 合成サンプルを再生成するスクリプト
- 一般化したテスト手順とプロンプト
- 個人名、絶対パス、元ファイル名を除いた数値結果
- 完全にオリジナルな汎用プロンプトから公開専用に新規生成し、後述の公開デモ権利ゲートを通過した画像、OBJ、3MF

公開サンプルには、作成方法、作成者、適用ライセンスを記録します。生成サービスの規約がCC BY 4.0などの条件を指定する場合、その条件を維持し、プロジェクト独自の判断でCC0へ変更しません。

### B. 動画表示には使うが、ファイル配布しないもの

- 自分が作成した、または動画表示の権利を確認した元画像
- 自分のアカウントで生成し、利用条件を確認した TripoAI の OBJ
- そこから ChromaMatter が生成した 3MF
- 自分で造形した物理サンプル

動画では必要以上に元ファイル名、保存場所、アカウント情報、モデル ID を表示しません。視聴者向けには「デモ表示のみ。モデル、元画像、3MF は配布物に含まれません」と明記します。

### C. 公開しないもの

- 権利を確認できない実モデル、画像、3MF
- 顧客、知人、第三者から預かったファイル
- 個人名、メールアドレス、ユーザー名、絶対パスを含む画面
- Downloads、Desktop、作業履歴、最近使ったファイルの表示
- API キー、トークン、ログイン情報
- 旧 EXE、recovered_pyc、由来不明アイコン
- デバッグ用の一時 STL、キャッシュ、クラッシュダンプ

既存の私有実モデル、元画像、派生3MFは、公開専用デモと見た目や生成経路が似ていてもCのままです。公開可否はファイル単位で判定します。

## 2. 「配布しない」と「動画に出せる」は別

OBJ や 3MF をダウンロード配布しなくても、YouTube、GitHub、応募資料への動画掲載は公衆への表示です。次を確認してから使用します。

- 元画像を動画に表示できる権利がある。
- 入力に人物、ブランド、既存キャラクター、第三者作品が含まれていないか確認した。
- TripoAI を利用した時点の契約プランと利用条件で、目的とする動画公開が認められている。
- 必要なクレジット表示がある場合は動画内または説明欄に記載した。
- 収益化、広告、企業応募など、商用と見なされ得る用途を含めて確認した。

Tripoの利用条件やプラン表記は変更される可能性があります。現在のPricingでFreeプランに`Public models (CC BY 4.0)`と表示される場合も、TermsのFree Userに関する権利条項を同時に確認します。Free出力を配布するときは、表示されたCC BY 4.0条件と帰属を維持し、所有権を主張したりCC0へ変更したりしません。Paidプランで広い利用・配布権が示される場合も、生成時のTermsとPricingを保存します。両者が食い違う、再配布条件が曖昧、または判断できない場合は公開せず、Tripoへ書面で確認します。

## 3. 公開デモと動画素材の権利記録

配布または動画に使う各サンプルについて、`samples/DEMO_MODEL_RIGHTS_RECORD_TEMPLATE_JA.md`を使って権利記録を残します。配布対象の記録から個人情報や非公開アカウント情報を除いた版は、モデルと一緒に公開します。

| 記録項目 | 記入内容 |
|---|---|
| 素材 ID | 公開画面に個人名を出さない管理番号 |
| 素材の種類 | 元画像、OBJ、3MF、印刷物、動画 |
| 作成者・入手元 | 自作、撮影者、生成サービスなど |
| 元画像の権利 | 自作、許諾、ライセンス、証拠の保存場所 |
| 生成の記録 | サービス、プラン、生成日、モデル ID、正確なプロンプト、seed |
| 条件の証拠 | Terms、Pricing、ライセンス表示の保存日と写し |
| 第三者要素 | 人物、ブランド、キャラクター、素材の有無 |
| 動画表示 | 可、不可、条件付き |
| ファイル再配布 | 可、不可、条件付き。根拠となる規約または許諾 |
| 適用ライセンス | CC BY 4.0、サービス指定条件、独自許諾など |
| 必要な表示 | 作者名、サービス名、CC BYリンクなど |
| ファイル照合 | 配布する各ファイルのファイル名とSHA-256 |
| 承認者・確認日 | 最終確認を行った人と日付 |

非公開素材の台帳には実ファイルを埋め込まず、アクセス制限したローカル保管場所との対応だけを記録し、台帳自体も公開しません。公開デモは、公開用記録と配布ファイルのSHA-256を一致させます。

## 4. 公開専用デモモデルの権利ゲート

汎用プロンプトから新規生成したという事実だけでは配布許可になりません。公開専用デモの画像、OBJ、3MFは、次をすべて満たした場合だけ公開stageへ追加できます。

- [ ] 生成サービス名、契約プラン、生成日、モデルIDを記録した。
- [ ] 省略していない正確なプロンプトと、使用した場合はnegative prompt、seed、各生成設定を記録した。
- [ ] 入力画像の作成者、入手元、利用・改変・再配布権を記録した。画像を入力していない場合も「入力画像なし」と記録した。
- [ ] 実在人物、既存キャラクター、ブランド、ロゴ、第三者作品に依存していないことを人間が確認した。
- [ ] 生成時と配布直前のTerms／Pricingを確認し、ファイル再配布の可否と条件を記録した。
- [ ] 適用ライセンスと必要な帰属表示を決定した。生成サービス側がCC BY 4.0を指定する場合はCC BY 4.0のままとし、CC0と表示していない。
- [ ] Tripo Freeを使った場合、PricingのCC BY 4.0表示だけでなくTermsの権利条項も確認し、両者が不明確なら公開を保留した。
- [ ] 公開する画像、OBJ、3MFごとにSHA-256を記録した。
- [ ] ChromaMatterでの変換やメッシュ修正後も、元生成物に付く条件を引き継いだ。
- [ ] `tooling/audit_public_tree.ps1`の監査に加えて、権利記録と実ファイルを人間が照合した。

実デモファイルがまだない段階では、このゲートを「未完了」のまま維持します。ファイルを先にGitへ追加し、後から権利を調べる順番にはしません。

## 5. 合成サンプルを公開する方針

公開テストでは、TripoAI の出力を必須にしない合成 OBJ を主に使用します。これにより、TripoAI を利用していない開発者でも、次を再現できます。

- 頂点カラーの読込
- 複数パーツの保持
- 16 色への量子化
- 色編集、塗り、簡易分割
- 3MF パッケージ生成
- 個人パスを含まない自動テスト

推奨する合成サンプルは、球、円柱、直方体、凹凸面を組み合わせた完全な新規形状です。既存キャラクターに似せず、テクスチャやロゴを含めません。生成スクリプトと乱数シードを一緒に公開すると、バイナリデータそのものより由来を説明しやすくなります。

## 6. 一般プロンプトの公開

一般的な検証用プロンプトは、文書サンプルとして公開できます。例:

> Create an original, non-branded abstract four-part figurine made from simple geometric forms. Use clearly separated large color regions, include light and shadow variation, avoid text, logos, known characters, and real people, and keep each part suitable for 3D printing.

このプロンプトは、特定サービスの利用を必須にするものではありません。プロンプトを公開しても、それを入力して生成されたモデルの権利や再配布許可まで自動的に与えるものではありません。利用者は、使用する生成サービスの規約と入力素材の権利を別途確認します。

プロンプトだけでは再現性が不足するため、公開検証の標準データにはプログラム生成した合成 OBJ を使います。公開専用デモモデルは追加の実演素材として扱い、正確なプロンプト、seed、生成設定、権利記録、SHA-256を併記します。

## 7. スクリーン録画前の個人データ対策

- 新しい Windows ローカルユーザーまたはデモ専用フォルダーを使う。
- ファイル名を demo_vertex_color.obj などの一般名に複製する。
- エクスプローラーのアドレスバー、最近使ったファイル、タスクバー通知を隠す。
- アプリのタイトル、ログ、エラーダイアログに絶対パスが出ないことを確認する。
- Orca のプロジェクト名、プリンタ名、ネットワーク機器名を確認する。
- 録画後、フレーム単位で個人情報と第三者素材を確認する。
- 公開版へ同梱するファイル一覧を動画素材フォルダーと完全に分離する。

## 8. 公開直前の判定

次のすべてが「はい」でなければ、そのサンプルは公開動画から外します。

- [ ] 元画像とモデルの由来を説明できる。
- [ ] 動画表示の権利を確認した。
- [ ] Tripo を使用した場合、生成時と公開時の条件を確認した。
- [ ] 必要な帰属表示を用意した。
- [ ] 私有ファイル本体をリポジトリ、ZIP、EXE に含めていない。
- [ ] 配布する公開専用デモは、権利記録、ライセンス、帰属表示、SHA-256が揃っている。
- [ ] 個人パス、個人名、アカウント情報を映していない。
- [ ] 第三者ブランドや既存キャラクターについて必要な許諾がある。
- [ ] 非配布素材と配布可能な公開デモを視聴者が区別できる。
