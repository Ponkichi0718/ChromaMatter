### DemoDataの最短手順

1. `OBJ / GLBを開く`からdemo GLBを読み込みます。
2. ［フィラメント設定］の［実機黒補正］で実際の最暗filament slotを選び、**必ず「黒弱め 5〜25%」presetを適用**します。
3. ［出力設定］で［閉立体化］を実行し、成功を確認します。
4. ［3MFを書き出す］から保存し、Snapmaker Orcaで**projectとして開いて**slice previewを確認します。

### DemoDataの注意

- importしたpart名はsemanticな印刷part名と一致する保証がありません。名前だけを信用せず、previewの表示／強調で対象を確認してください。
- 「黒弱め」は選択した黒slotを含む混色の3MF出力比率へ作用します。表示色、自動配色、純黒slotそのものを一律に変更する機能ではありません。
- Hi3D系分割GLB対応はβ・非公式です。すべてのHi3D出力との互換性を保証しません。
- 元画像は見た目を確認するためのreferenceで、自動投影や自動retextureを行いません。

## English

ChromaMatter 0.8beta r32.1 is a post-r32 update. It retains the published r32 contracts for model processing, multipart GLB solidification, narrow identification-colour suppression, manual paint, and Full Spectrum 3MF export.

### What changed

- Renamed the preview heading from `Original Tripo Color` to the provider-neutral `AI Model Color`.
- Added a rights-cleared Hi3D multipart GLB and its reference image under `DemoData/` in the Windows ZIP.
- The bundled GLB is **Generated by Hi3D**. Hi3D compatibility is unofficial beta support and does not imply affiliation or endorsement.
- Added short Japanese and English demo instructions covering load, solidify, and 3MF export.
- Published `v0.8beta-r32` remains unchanged. Its tag, assets, and checksums are immutable previous evidence; r32.1 uses a new tag and new asset names.

### Short DemoData workflow

1. Use `Open OBJ / GLB` to load the demo GLB.
2. Under **Filament Settings > Physical Black Correction**, select the actual darkest filament slot and **always apply the Weak Black 5–25% preset**.
3. Under **Output Settings**, run **Solidify** and confirm success.
4. Export 3MF, open it **as a project** in Snapmaker Orca, and inspect the slice preview.

### DemoData cautions

- Imported part names are not guaranteed to match semantic print-part names. Verify each target with preview visibility/highlighting instead of trusting the name alone.
- Weak Black changes 3MF output ratios for mixed states that contain the selected black slot. It does not globally change displayed colour, automatic mapping, or the pure-black slot.
- Hi3D-style multipart GLB support is beta and unofficial. Compatibility with every Hi3D output is not guaranteed.
- The reference image is for visual comparison; it is not automatically projected or used to retexture the model.
