## 日本語

r32.2は、表示version `0.8beta`、Windows数値version `0.8.0.0`、既存のmodel処理／
3MF安全契約を維持し、公開用DemoDataへ7個の派生3MFを追加しました。Windows ZIP、
完全対応source、SBOM、component map、操作動画、detached checksumは生成・検証・
公開済みです。

### 収録した派生3MF

`DemoData/3MF/`には、`Original AI model Color.glb`からChromaMatterで生成した
150 mm高、32 palette state／4 physical filamentの参考出力を収録します。

- `Original AI model Color_FullSpectrum.3mf` — 6 meshを含む結合project
- `Original AI model Color_FullSpectrum_parts_2/01_RightArm_FullSpectrum.3mf`
- `Original AI model Color_FullSpectrum_parts_2/02_LeftLeg_FullSpectrum.3mf`
- `Original AI model Color_FullSpectrum_parts_2/03_Head_FullSpectrum.3mf`
- `Original AI model Color_FullSpectrum_parts_2/04_LeftArm_FullSpectrum.3mf`
- `Original AI model Color_FullSpectrum_parts_2/05_Torso_FullSpectrum.3mf`
- `Original AI model Color_FullSpectrum_parts_2/06_RightLeg_FullSpectrum.3mf`

上記7件の3MFとは別に、同じdirectoryへcompanion record
`Original AI model Color_FullSpectrum_parts_2/パーツ別3MF_manifest.json`を
同梱します。

Hi3D由来のpart labelは見た目の部位と一致しないため、個別3MFのfilenameだけで
判断せず、必ずgeometryを確認してください。demoを自分で再出力するときは、実際に
黒filamentを入れるF slotを選び、3MF出力前に**必ず「黒弱め 5〜25%」presetを
適用**してください。

同梱の3MFは参考出力であり、印刷可能性の保証ではありません。6 partは閉立体と
して確認されていますが、継承された微小自己交差warningが残るため、Snapmaker Orcaで
projectとして開き、part、material、tool順、slice previewを確認してください。

**0.8betaの重要な制限:** パーツ化モデルの閉立体化はまだ不安定です。
同梱の`DemoData`は閉立体化・3MF出力の成功を確認していますが、
他の分割ファイルでは閉立体化または3MF出力に失敗することがあります。これは
ChromaMatterを`0.8beta`としている理由の一つです。

## English

The r32.2 prerelease keeps the public display version at `0.8beta`, the Windows
numeric version at `0.8.0.0`, and the existing modelling and fail-closed 3MF
safety contracts. It adds seven derived 3MF files to the public DemoData. The
Windows ZIP, complete corresponding source, SBOM, component map, workflow
video, and detached checksums have been built, validated, and published.

### Included derived 3MF files

`DemoData/3MF/` contains reference output generated by ChromaMatter from
`Original AI model Color.glb`: a 150 mm, 32-palette-state / four-physical-
filament project.

- `Original AI model Color_FullSpectrum.3mf` — combined project with six meshes
- `Original AI model Color_FullSpectrum_parts_2/01_RightArm_FullSpectrum.3mf`
- `Original AI model Color_FullSpectrum_parts_2/02_LeftLeg_FullSpectrum.3mf`
- `Original AI model Color_FullSpectrum_parts_2/03_Head_FullSpectrum.3mf`
- `Original AI model Color_FullSpectrum_parts_2/04_LeftArm_FullSpectrum.3mf`
- `Original AI model Color_FullSpectrum_parts_2/05_Torso_FullSpectrum.3mf`
- `Original AI model Color_FullSpectrum_parts_2/06_RightLeg_FullSpectrum.3mf`

The package also carries the companion record
`Original AI model Color_FullSpectrum_parts_2/パーツ別3MF_manifest.json`; it is
not counted among the seven derived 3MF outputs.

The Hi3D-derived part labels do not match the visible body regions. Inspect the
geometry instead of relying on an individual filename. When regenerating the
demo, select the F slot that will physically hold black filament and **always
apply the Weak Black 5–25% preset before 3MF export**.

These files are reference outputs, not a printability guarantee. All six parts
were confirmed watertight, but inherited minor self-intersection warnings
remain. Open the result as a project in Snapmaker Orca and inspect parts,
materials, tool order, and the slice preview.

**Important 0.8beta limitation:** Solidification of multipart models is still unstable.
The bundled `DemoData` is a confirmed successful case, but other multipart files may fail to solidify or export as 3MF.
This is one reason ChromaMatter remains `0.8beta`.
