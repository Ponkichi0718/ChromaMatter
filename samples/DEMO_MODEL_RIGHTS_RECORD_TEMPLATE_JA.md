## 6. サービス規約と再配布根拠

生成日と公開直前の両方について記録します。規約は変更されるため、URLだけでなく確認日と、必要に応じて画面またはPDFの非公開保存先も残します。

| 確認対象 | URL | 確認日 | 該当プラン／条項 | 保存した証拠の管理ID |
|---|---|---|---|---|
| 生成サービスTerms |  |  |  |  |
| 生成サービスPricing／Plan |  |  |  |  |
| ライセンス表示 |  |  |  |  |
| 書面確認がある場合 |  |  |  |  |

TripoAIを使う場合の一次情報:

- Tripo Terms of Service: https://www.tripo3d.ai/terms
- Tripo Pricing: https://www.tripo3d.ai/pricing
- Creative Commons Attribution 4.0: https://creativecommons.org/licenses/by/4.0/

確認時の注意:

- 現在のFreeプラン表示が`Public models (CC BY 4.0)`であっても、Termsの権利条項も同時に読み、表示された条件と必要な帰属をそのまま記録します。所有権を主張したりCC0へ変更したりしません。
- Paidプランで広い利用・配布権が示される場合も、生成時のプランとTerms／Pricingの確認記録を残します。
- TermsとPricingの意味が食い違う、再配布が明記されていない、または判断できない場合は`要確認`とし、公開せず、サービス提供者から書面確認を得ます。
