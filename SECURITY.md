# Security policy

Please do not report a suspected security vulnerability in a public Issue or
Discussion. Use GitHub's private
[Report a vulnerability](https://github.com/Ponkichi0718/ChromaMatter/security/advisories/new)
form instead.

Include the ChromaMatter source commit or Release tag, operating system,
minimum reproduction steps, expected result, and actual result. Remove API
keys, account details, personal paths, private filenames, private models, and
customer data. A public test model or a minimal description is preferred.

Ordinary startup, colour, UI, import, export, and Snapmaker Orca compatibility
problems belong in the normal Issue forms. The private form is only for a
problem that could affect confidentiality, integrity, code execution, or user
safety before it can be discussed publicly.

ChromaMatter is an independently developed `0.8beta` project. A private report
does not imply a fixed response time or production support, but it gives the
maintainer a safe place to investigate before disclosure.
